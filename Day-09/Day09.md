# 🥗 NutriScope Pro

An AI-powered Nutrition Analytics Platform that helps users track food intake, analyze nutritional patterns, identify potential deficiencies, and receive personalized dietary recommendations.

This project was built as part of **Day 9/60 – Claude AI Challenge** and demonstrates how a basic nutrition tracking MVP can be transformed into a more advanced health analytics solution.

---

## 🚀 Features

### 🔹 Version 1 (MVP)

- User Profile Management
- Food Logging System
- Calorie Tracking
- Macro Nutrient Analysis
- Essential Micronutrient Tracking
- Energy Progress Dashboard
- Personalized Nutrition Recommendations

### 🔹 Version 2 (Enhanced)

- CSV Food Log Upload
- Expanded Food Database
- Additional Micronutrient Analysis
- Interactive Nutrition Dashboard
- Advanced Charts & Visualizations
- Risk Analysis Engine
- 2-Day Smart Meal Planner
- Smart Nutrition Insights
- Enhanced Recommendation System
- Nutrition Sources & References
- Educational Disclaimer

- Zinc

### Risk Assessment

Detect potential nutritional concerns such as:

- Low Fiber Intake
- Iron Deficiency Risk

### Smart Recommendations

Receive personalized suggestions based on nutritional gaps and dietary patterns.

Generate simple meal plans designed to improve nutritional balance.
