# 🧩 Prompt Puzzle — Master AI Prompting Through Play

An interactive, offline-first educational web application designed to teach **AI Prompt Engineering** through gamified learning experiences.

Prompt Puzzle transforms prompt writing into a series of engaging challenges where users construct, optimize, and evaluate prompts while learning industry best practices.

## ✨ Features

* Domain-based prompt training
* Beginner, Intermediate, and Advanced difficulty levels
* Randomized learning scenarios
* Three unique challenge types

  * Build the Prompt
  * Clean the Prompt
  * Choose the Best Prompt
* Drag-and-drop gameplay
* Live scoring system
* Accuracy, Time, Moves, Hint, and Optimization tracking
* Prompt Performance Report
* Prompt DNA visualization
* Personalized AI feedback
* Replay with newly generated scenarios
* Modern responsive UI with animations and micro-interactions
* Offline support (Single HTML file)

## 🛠 Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* Drag & Drop API
* Local JavaScript Data Objects

## 🎯 Learning Outcomes

This project helps users understand:

* Writing clear and structured prompts
* Eliminating unnecessary prompt complexity
* Improving AI response quality
* Applying prompt engineering principles to real-world tasks
* Building optimized prompts for Data Science and Analytics workflows
