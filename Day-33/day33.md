# 📰 Media Integrity Analyzer

Day 33 of my 60 Days of AI Challenge.

Media Integrity Analyzer is an interactive educational web application that teaches users how to critically evaluate digital content. Instead of relying on quizzes, it provides guided experiences where users first react naturally to fictional headlines and social media posts, then discover the techniques used to influence attention, emotions, and decision-making.

## Features

- Interactive Headline Detective challenge
- Emotion Detector with guided analysis
- Fictional news articles and social media scenarios
- Headline Accuracy evaluation
- Source Reliability indicator
- Emotional Manipulation analysis
- Audience Targeting insights
- Personalized Media Integrity Dashboard
- Overall Media Integrity Score
- Practical media literacy tips
- Replay with new randomized scenarios
- Multiple color themes including Claude Orange
- Smooth animations and responsive editorial-style UI
- Fully offline single-file application
- Built using Vanilla HTML, CSS, and JavaScript

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Learning Outcomes

This project demonstrates how interactive design can be used to teach media literacy through discovery instead of memorization. Users learn to identify exaggerated headlines, emotional triggers, manipulation techniques, audience targeting strategies, and practical habits for evaluating online content more critically.

Building this project strengthened my skills in frontend development, UI/UX design, state management, interactive storytelling, responsive layouts, and educational application design.
