# 🚚 AI Supply Chain Control Tower

An interactive web application that simulates the role of a **Head of Operations** managing a global supply chain. Respond to real-time disruptions, prioritize critical alerts, and make strategic decisions that directly impact business performance before time runs out.

## ✨ Features

- 📊 Live KPI dashboard with real-time business metrics
- 🚨 Dynamic operational alerts with multiple priority levels
- 🎯 Decision-based gameplay where every action affects the business
- 📈 Increasing difficulty with more alerts over time
- 📋 Live event log to track operational decisions
- 🏆 Final performance report with score, grade, and KPI summary
- ⏸️ Pause, Help, Sound Toggle, and Replay functionality
- 🌙 Premium dark dashboard inspired by enterprise control towers
- 📱 Fully responsive design for desktop and mobile

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 🎮 Gameplay

Take charge as the Head of Operations and manage supply chain disruptions including supplier delays, port congestion, warehouse stockouts, customs inspections, truck breakdowns, demand spikes, factory failures, and weather disruptions.

Choose the best response for each alert, protect revenue, improve customer satisfaction, optimize transportation, and maintain healthy inventory levels while racing against the clock.

## 🚀 Highlights

- Single self-contained HTML file
- Works completely offline
- No frameworks or external libraries
- Smooth animations and modern UI
- Modular JavaScript structure
- Interactive business simulation with real operational decision making

This project combines frontend development, UI/UX design, gamification, and supply chain concepts into an engaging learning experience that demonstrates how operational decisions influence key business metrics.
