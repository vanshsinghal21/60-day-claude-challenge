# 🏥 Prior Authorization Workflow Simulator

An interactive healthcare workflow simulator that visualizes the U.S. Prior Authorization (PA) process through a modern, gamified interface.

## ✨ Features

* 🎯 Interactive workflow simulation
* 👨‍⚕️ Patient, Provider & Payer lanes
* 📋 Medical necessity evaluation
* 📑 Prior authorization documentation
* 📤 Payer submission workflow
* ✅ Approval, Pend, Denial, Appeal & Peer-to-Peer outcomes
* 📈 Progress tracker and efficiency score
* ⏱️ Days elapsed monitoring
* 🎉 Workflow completion summary
* 📱 Responsive healthcare dashboard UI

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript

A visual learning tool designed to simplify and demonstrate the end-to-end Prior Authorization process using an engaging, dashboard-style experience.
