# Football Intelligence Hub ⚽

### Day 19/60 – Claude AI Challenge

An AI-powered football analysis platform that combines World Cup predictions, football knowledge assessment and personality matching into one interactive experience.

## Features

* FIFA World Cup 2026 Prediction Report
* Historical and current team performance analysis
* Winner, runner-up and dark horse predictions
* Players to Watch insights
* Football IQ Quiz
* Football Awareness Score
* Fan Classification System
* Messi vs Ronaldo Personality Match
* Football Personality Archetype Detection
* Personalized football recommendations

## Concepts Used

* Prompt Engineering
* Sports Analytics
* Personality Assessment
* Interactive Quiz Design
* Data Interpretation
* AI-Powered Reporting

## Key Outcome

This project demonstrates how AI can transform structured football data into personalized insights, predictions and engaging user experiences.

Built as part of the ABTalks 60 Day Claude AI Challenge – Day 19.
