# AI Powered Life Analysis Report Generator

An AI-powered consultant that analyzes user inputs and generates a personalized life analysis report with actionable insights and recommendations.

## Features

- Structured user input collection
- Multi-dimensional life analysis
- Career and wealth insights
- Relationship analysis
- Current phase assessment
- Future outlook generation
- Personalized recommendations
- Clean and organized report structure

## Areas Covered

- Life Overview
- Strengths & Growth Areas
- Career Path Insights
- Financial Guidance
- Relationship Insights
- Current Phase Analysis
- Future Outlook
- Actionable Recommendations

## Key Learnings

- Prompt Engineering
- AI Personalization
- Structured Analysis Frameworks
- Report Generation Systems
- Domain Specific AI Applications

## Tech Stack

- Claude AI
- Prompt Engineering
- Structured Analysis Framework
- Generative AI

## Project Goal

To demonstrate how AI can transform structured user inputs into meaningful insights and personalized guidance through intelligent report generation.
