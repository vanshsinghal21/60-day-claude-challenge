# Face Puzzle Game

An interactive AI-assisted Face Puzzle Game built using HTML, CSS and JavaScript. The application captures a user's photo through the webcam and transforms it into a playable puzzle with multiple difficulty levels.

## Features

- Webcam integration using Browser APIs
- Capture and use your own face as the puzzle image
- Multiple difficulty levels
  - 3 × 3 Grid
  - 4 × 4 Grid
  - 5 × 5 Grid
- Dynamic puzzle piece generation
- Drag and drop controls
- Touch support for mobile devices
- Live timer tracking
- Move counter
- Correct piece progress tracker
- Automatic win detection
- Result screen with performance summary
- Local leaderboard using localStorage
- Responsive design for desktop and mobile
- Retake photo and replay functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Canvas API
- MediaDevices API
- Local Storage

## How It Works

1. Allow camera access.
2. Capture a photo using the webcam.
3. Select a puzzle difficulty.
4. Start the game.
5. Rearrange the scrambled pieces.
6. Complete the puzzle to view results and leaderboard.
